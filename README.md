# Weather Dashboard App

A responsive weather application built while learning JavaScript and working with APIs.

The app allows users to:

- Search for weather information by city name
- View the current weather and a 5-day forecast
- Use their current location to get weather information
- View temperature, wind speed, humidity, and weather conditions

## Technologies Used

- HTML
- CSS
- JavaScript
- OpenWeather API
- Netlify Functions

## What I Learned

While building this project, I practiced:

- Working with APIs using `fetch()`
- Using `async/await` and `try...catch`
- Handling API errors
- Working with JavaScript arrays and objects
- Manipulating the DOM
- Using browser geolocation
- Deploying a project with Netlify

This project is part of my frontend development learning journey, and I plan to continue improving it as I learn more.
